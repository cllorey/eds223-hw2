# EDS 223 Homework 2: Exploring patterns of environmental justice

## Purpose
This repository contains data and code to explore and visualize the legacy of historical redlining in Los Angeles, specifically evaluating its impact on the wealth and health of communities. In particular, this project utilizes 1) data from the Mapping Inequality project at the University of Richmond's Digital Scholarship Lab to look at HOLC grade designations for Los Angeles, 2) data from the US Environmental Protection Agency EJScreen tool to look at demographic and air quality indicators in 2023, and 3) data from the Statewide Integrated Traffic Records System (SWITRS) database to look at pedestrian and bike crashes/fatalities from 2020 to 2025.

## Data Access
The data used in this project originated from the following sources:

1. The Mapping Inequality project at the University of Richmond's Digital Scholarship Lab, which houses digitized maps and information from the HOLC. Mapping inequality data can be accessed on the [project site](https://dsl.richmond.edu/panorama/redlining/data). The specific dataset used in this exercise can be downloaded using [this link.](https://drive.google.com/file/d/14x1CTz3ZUJdm8_8625OGM5W32TkcCife/view?usp=sharing)

2. The United States Environmental Protection Agency’s former EJScreen: Environmental Justice Screening and Mapping Tool. As the EPA EJScreen tool and official website is no longer available, data was accessed from a Google Drive folder provided on the [EDS 223 Course Website](https://eds-223-geospatial.github.io/assignments/HW2V2.html). It can be downloaded using [this link.](https://drive.google.com/file/d/14x1CTz3ZUJdm8_8625OGM5W32TkcCife/view?usp=sharing) 

3. The Statewide Integrated Traffice Records System (SWITRS) database, which collects and processes data gathered from collisions. The data is hosted on the [Transportation Information Mapping System (TIMS)](https://tims.berkeley.edu/), developed by UC Berkley SafeTREC. The specific dataset used in this exercise can be downloaded using [this link.](https://drive.google.com/file/d/14x1CTz3ZUJdm8_8625OGM5W32TkcCife/view?usp=sharing)
